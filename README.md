# SoundCapsule (사운드 다이어리 & 요일별 피아노) — UI/UX 프로토타입

> **Visual Philosophy:** Radical Minimalism & Tactile Acoustic Keys ([Ollama DESIGN.md](https://oh-my-design.kr/design-systems/ollama))  
> 일상의 소리를 녹음하고, 날짜와 장소를 따라 그 순간을 다시 듣는 서비스입니다. 녹음한 날의 요일에 맞춰 피아노 건반이 파스텔톤으로 채워지고, 열린 건반으로 나만의 멜로디를 연주할 수 있습니다. Ollama 특유의 극단적 미니멀리즘(Pure Black, White Canvas, Full Pill Buttons, 1px Crisp Borders)에 파스텔 7색 피아노를 감성적으로 결합했습니다.

---

## 🎨 디자인 시스템 & 스타일 가이드 (Ollama Design Rules)

1. **Ollama Minimalist 모노크롬 & 파스텔 7색 악센트**
   - **Canvas & Primary:** `#FFFFFF` (순백 캔버스), `#000000` (순흑 CTA 및 헤드라인)
   - **Subtle Surface & 1px Border:** `#F9F9FB`, `#E4E4E7` (1px 미세 테두리로 그림자 없이 단정하고 현대적인 마감)
   - **Extreme Pill Shapes (`border-radius: 9999px`):** 모든 버튼, 인풋 태그, 배지, 내비게이션 요소에 완벽한 둥근 알약 형태 적용
   - **Typography:** 헤딩 및 브랜드(`Plus Jakarta Sans`), 본문(`Pretendard`), 메타데이터 및 건반 카운터(`JetBrains Mono`)

2. **🎵 요일별 파스텔 피아노 시스템 (Weekly Pastel Piano)**
   - **월~일 7개 요일과 도~시 7음계 1:1 매핑:**
     - 월: **도(C4)** / 빨강 (`#F43F5E`)
     - 화: **레(D4)** / 주황 (`#FB923C`)
     - 수: **미(E4)** / 노랑 (`#FACC15`)
     - 목: **파(F4)** / 초록 (`#4ADE80`)
     - 금: **솔(G4)** / 파랑 (`#60A5FA`)
     - 토: **라(A4)** / 남색 (`#818CF8`)
     - 일: **시(B4)** / 보라 (`#C084FC`)
   - **채움 진행도 (아래에서 위로 차오르는 수직 게이지 & 하단 카운터 `2/4`):**
     - `0일 (0%)`: 잠김 🔒
     - `1일 (25%)`: 잠김 🔒 (터치 시 *"월요일에 한 번 더 녹음하면 도가 열려요"* 안내 툴팁)
     - `2일 (50%)`: **연주 가능 🎹** (터치 시 실제 맑은 어쿠스틱 피아노 소리 출력)
     - `3일 (75%)`: 연주 가능 🎹
     - `4일 이상 (100%)`: 연주 가능 🎹 (완전 채움)
   - **완성 배너:**
     - 7개 음 모두 열렸을 때: *"모든 음을 연주할 수 있어요! 🎶"*
     - 7개 건반 모두 100% 채웠을 때: *"🎉 이번 달 피아노 완성!"*
   - **월간 리셋 & 보관함:** 매월 1일 새달의 피아노 시작, 지난달 피아노(10월)는 보관함에서 언제든 다시 열람 및 연주 가능

## 📱 6개 하단 탭 핵심 기능

| 하단 탭 | 핵심 UI/UX 인터랙션 |
| :--- | :--- |
| **1. 홈 · 소리 녹음** | 원터치 녹음 + 실시간 파형 + 날짜·시간 자동 기록 + 장소 설정 시트.<br>• **녹음 중일 때 버튼 문구: `"녹음 종료"` 명시 (사용자 피드백 반영)**<br>• 저장 시 캘린더, 지도, 그리고 **오늘 요일의 피아노 건반 진행도에 자동 반영!** |
| **2. 캘린더 · 날짜별 기록** | 월별 캘린더 날짜 선택 및 녹음 카드 확인, 인라인 Web Audio 재생(파도·비·바람). 사진 및 메모 첨부/수정.<br>• **캘린더 하단에 `🎹 10월의 피아노 · 완성 7/7` 배지 표시 (클릭 시 보관함 모달 오픈 및 연주)** |
| **3. 지도 · 장소별 기록** | 지역 핀 지도 & **🌐 3D 인터랙티브 지구본 탐색** 모드.<br>• 상단 플로팅 **재방문 알림 토스트** (*"📍 3개월 전에 이곳을 방문했어요. 그날의 소리를 다시 들어볼까요?"*) + 당시 소리 바로듣기 |
| **4. 🎵 음표 · 요일별 피아노** | **본 기획의 핵심 인터랙션 탭!**<br>• 7개 파스텔 건반 수직 차오름 및 실시간 연주<br>• 잠긴 건반 탭 시 친절한 남은 녹음 횟수 안내 토스트<br>• 상단 완성 축하 배너 및 지난 피아노 보관함 열람 |
| **5. 친구 · 공유 & 친구 음표** | 친구 ID 검색 추가, 그룹 사운드 캡슐 생성 및 공유 피드.<br>• **`🎵 친구 음표 보기` 버튼: 친구가 이번 달에 채운 파스텔 건반을 구경하고, 친구의 열린 건반을 직접 터치해 연주!** |
| **6. 설정 · 환경 설정** | 계정/프로필 관리, 소리 옵션(노이즈 리덕션, 무손실 고음질 FLAC 24-bit), 재방문 알림 On/Off, 사진 앱 자동 연동 |

## 🚀 로컬 실행 방법

```bash
# 개발 서버 시작
npm run dev
```

* 브라우저 상단에서 **[📱 모바일 뷰]** 와 **[💻 데스크톱 뷰]**를 클릭해 반응형 레이아웃을 전환할 수 있습니다.
* 우측 상단의 **[📐 Ollama DESIGN.md 스펙]**을 누르면 미니멀 컬러 토큰(원클릭 Hex 복사)과 건반 매핑 표, 디자인 규칙을 실시간으로 확인할 수 있습니다.
